Download all the files.
Place the files Board.java,Pieces.Java, MainMenu.java and Main.java in a project inside the source Package in a Package  CHESS (NOT THE DEFAULT PACKAGE).
Open the Netbeans Project using file explorer and make a new folder called resources inside the src. Inside resources create a new folder called CHESS. Drop all the PNG's inside that folder
Double click on the Main.java program click run file.
Extra note: During promotion after clicking on your desired piece in the pop up window also click on the pawn which has to be promoted in order for the pawn to actually change to the chosen piece.
After all these work the project should work smoothly.
